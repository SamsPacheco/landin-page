# 🛍️ Siman Landing Pages – Promociones de Tecnología y Membresía VIP - Actividad Kodigo

Este repositorio contiene un conjunto de **landing pages diseñadas para la cadena de tiendas Siman**, orientadas a promocionar productos tecnológicos, accesorios de sonido y beneficios exclusivos para miembros VIP.

El sitio fue desarrollado con enfoque visual atractivo, buena jerarquía de contenido y una experiencia clara para el usuario final.

## 💡 Funcionalidades principales

- 🎯 Sección destacada de **promociones por categoría** (Tecnología / Sonido)
- 🛒 Tarjetas de productos con:
  - Imagen de producto
  - Título, marca, precios (original y VIP)
  - Botón de compra (CTA)
- 🔐 Página exclusiva para **miembros VIP**
  - Beneficios de ser miembro del club Siman (descuentos, eventos, promociones anticipadas)
- 📨 Formulario de suscripción a newsletter
- 💬 Testimonios de clientes satisfechos
